## 🛡️ Secure Pass Pro v4.0

> Профессиональный генератор и менеджер паролей с открытым исходным кодом.  
> Всё шифрование - локально. Мастер-пароль никогда не покидает устройство.

---

### ✨ Новое в v4.0

| | Функция | Описание |
|---|---------|----------|
| 🛡️ | **Визуальная индикация силы** | Иконка щита меняет цвет в реальном времени: 🔴 → 🟠 → 🟡 → 🟢 |
| 🎲 | **Diceware фразы-пароли** | Генерация паролей из слов (~13 бит энтропии на слово) |
| 📂 | **Импорт KeePass .kdbx** | Полная поддержка зашифрованных баз KeePass 4 |
| 🔐 | **Импорт 1Password .1pux** | Экспорт из 1Password без потери данных |
| ☁️ | **Облачная синхронизация** | WebDAV (Nextcloud и любой совместимый сервер) |
| ⌨️ | **Auto-Type** | Автоматический ввод пароля в активное поле |
| ⭐ | **Избранное в базе** | Пометка записей + фильтр по категориям, email, URL |
| 📄 | **Кириллица в PDF** | Корректный экспорт русского/украинского текста (шрифт DejaVu) |
| 🌐 | **3 языка интерфейса** | Русский, English, Українська - полное покрытие всех экранов |

### 🔧 Исправления v4.0

- **#56** - Исправлен краш RGB-анимации при закрытии окна
- **#55** - Унифицированы параметры SCrypt во всех модулях шифрования
- **#54** - Исправлен порядок инициализации путей при запуске (ImportError на некоторых системах)
- **#52** - Портативный режим теперь требует явный файл `PORTABLE.txt`
- **#51** - Запрет копирования/pickle для `SecureBytes` и `SecurePassword`
- **#50** - Улучшена функция `secure_zero_string`: несколько стратегий перезаписи
- **#48** - XXE-защита для XML-парсинга: лимит размера и глубины
- **#47** - Переименован `ImportError` → `PasswordImportError` (конфликт с built-in)
- **#46** - Анти-отладка для Linux/macOS: обнаружение `ptrace`
- **#45** - Исправлена структура `CONTEXT` для x64 Windows
- **#38** - Атомарные операции записи через `os.replace`
- **#33** - Исправлено позиционирование диалогов (`update_idletasks` + `after`)
- **#22** - Thread safety: добавлены `threading.RLock` во все критические секции

### 🔒 Стек безопасности

```
AES-256-GCM   - шифрование базы паролей (SQLCipher)
Argon2id      - хэширование мастер-пароля
PBKDF2        - дополнительное key derivation
TOTP RFC 6238 - двухфакторная аутентификация
CSPRNG        - генерация паролей (secrets)
HIBP          - проверка утечек (k-Anonymity, пароль не передаётся)
5× overwrite  - безопасная очистка буфера обмена
ctypes.memset - очистка чувствительных данных в памяти
```
