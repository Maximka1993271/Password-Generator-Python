# 🔐 Secure Pass Pro v4.0

## 🚀 Что нового

### 🎬 Анимация кнопок (v4.0)
- **Живой отклик** – Текст кнопок мгновенно сжимается при нажатии, обеспечивая четкую визуальную обратную связь
- **Механический звук клика** – Синхронизирован с анимацией для приятного тактильного отклика
- **Плавность** – Анимация длится 60 мс, не мешая быстрому использованию
- **Кроссплатформенность** – Работает на Windows, macOS и Linux

### 🌈 RGB подсветка ВСЕГО окна
- **Полная RGB анимация** – Динамическая подсветка **всех границ** главного окна (верх, низ, лево, право)
- **Заголовок Windows 11** – Кнопки **"Закрыть"**, **"Свернуть"**, **"Развернуть"** меняют цвет вместе с анимацией
- **30 FPS** – Плавная, энергоэффективная анимация
- **Управление из настроек** – Кнопки "Вкл"/"Выкл" с сохранением состояния
- **Независимые цветовые фазы** – Каждая сторона окна имеет свою фазу для волнового эффекта
- **Синхронизация с полем пароля** – Поле пароля также имеет цветную пульсацию

### 💾 Новая функция: Автосохранение
- **Автоматическое сохранение паролей** – При включённой опции каждый сгенерированный пароль автоматически сохраняется в базу
- **Кнопка в настройках** – Удобное включение/выключение из окна настроек
- **Метка с датой** – Пароли сохраняются с меткой `Auto 2026-05-14 15:30:00`
- **Перевод на 3 языка** – Полная поддержка RU/EN/UA
- **Сохранение состояния** – Настройка сохраняется в `config.json`

### 🏗️ Модульная архитектура
- **Полная реорганизация** – Разделение на модули: `core/`, `gui/`, `security/`, `storage/`, `localization/`, `utils/`
- **Улучшенная поддержка кода** – Легче добавлять новые функции и исправлять ошибки
- **Чистая структура** – Каждый модуль отвечает за свою область

### 🔒 Улучшения безопасности
- **Защита мастер-паролем** – Argon2id хеширование (современный стандарт) + PBKDF2 fallback (600,000 итераций)
- **Контроль целостности файлов** – SHA-256 проверка при открытии
- **Защита от повторов символов** – Исключает повторяющиеся символы подряд (например, `aaa`, `111`)
- **Настраиваемая очистка буфера** – Таймаут от 10 до 120 секунд
- **Умная очистка буфера** – Очищается только если пароль не изменился
- **Защита от SQL-инъекций** – Все запросы параметризованы
- **Secure delete для SQLite** – Удалённые данные не восстанавливаются
- **Защита от timing-атак** – `hmac.compare_digest()`
- **Криптостойкое перемешивание** – Fisher-Yates + `secrets.randbelow()`

- **Неоновая пульсация** – Визуальная индикация силы пароля

## 🔧 Исправления v4.0.10

### 🎨 Устранение артефактов сглаживания при смене темы
- **Правильный порядок применения темы** – `ctk.set_appearance_mode()` теперь вызывается до применения цветов, а не после; цвета применяются через `after(50 мс)` — после того как CTk завершил перерисовку
- **Синхронизация фона окна** – `self.configure(fg_color=...)` явно выставляет фон CTk-окна, устраняя просветы под скруглёнными виджетами
- **RGB-канвасы** – Фон `tk.Canvas` теперь синхронизируется с фоном окна при каждой смене темы

### 🗂️ Папка `data` теперь скрытая (Windows)
- **`storage/database.py`** – Атрибут Hidden (`0x02`) устанавливается в `_get_connection()` сразу после `os.makedirs`
- **`storage/config.py`** – Атрибут Hidden устанавливается в `save()` сразу после `os.makedirs`; исправлен путь — теперь `data/` рядом с приложением вместо `~/.securepasspro`
- **`security/master.py`** – Атрибут Hidden устанавливается в `set_password()` сразу после `os.makedirs`; исправлен путь аналогично

### ⚙️ Полный `config.json` при первом запуске
- При первом запуске (или неполном файле) синглтон `Config` синхронизируется со всеми дефолтными значениями через `self.config.update(config)` — файл сразу записывается полностью со всеми 10 ключами

### 🌟 Убрана полоска под звёздами
- Нижний фрейм со звёздами (`bottom_frame`) сделан прозрачным (`fg_color="transparent"`) — подложка исчезает в обеих темах, звёзды остаются

## 📦 Установка

### Вариант 1: Скачать исполняемый файл (Windows)
1. Скачайте `SecurePassPro.exe` из раздела [Releases](https://github.com/Maximka1993271/Password-Generator-Python/releases)
2. Запустите файл – установка не требуется

### Вариант 2: Запуск из исходного кода
```bash
# Клонирование репозитория
git clone https://github.com/Maximka1993271/Password-Generator-Python.git
cd Password-Generator-Python

# Установка зависимостей
pip install customtkinter qrcode[pil] pillow fpdf argon2-cffi

# Запуск
python Secure_Pass_Pro.pyw
```
