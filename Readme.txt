# 🔐 Secure Pass Pro v4.0

**Профессиональный генератор и менеджер паролей с открытым исходным кодом**

---

## 📋 О программе

**Secure Pass Pro v4.0** — это профессиональный генератор и менеджер паролей с открытым исходным кодом. Программа построена на Python и CustomTkinter, сочетает криптостойкую генерацию, многоязычный интерфейс, полное шифрование данных и современный дизайн с RGB-анимацией.

| Параметр | Значение |
|----------|----------|
| **Автор** | Максим Мельников |
| **Лицензия** | MIT (бесплатно) |
| **Версия** | 4.0.0 |
| **Платформы** | Windows, macOS, Linux |
| **Языки** | Русский, English, Українська |

---

## 🚀 Основные возможности

- 🔐 **Продвинутый генератор паролей** (CSPRNG, 8 параметров)
- 👤 **Генератор имён** (8 режимов: SAMP RP, Email, Игровой ник и др.)
- 🌐 **Полная поддержка 3 языков** (RU, EN, UA с динамическим переключением)
- 🔒 **AES-256-GCM шифрование** + SQLCipher
- 🛡️ **Argon2id защита мастер-пароля** + PBKDF2 fallback
- 🧹 **Безопасная очистка памяти** (ctypes.memset)
- 🔑 **Защита буфера обмена** (Windows API, 5-кратная перезапись)
- ⏱️ **Автоблокировка** при бездействии
- 🚨 **Panic mode** — аварийная очистка (Ctrl+Alt+Shift+P)
- ✅ **HMAC-SHA256** контроль целостности
- 🎨 **Современный GUI интерфейс** (как в Microsoft Edge)
- 🌙 **Поддержка тёмной темы**
- 🌈 **RGB анимация** (настройка скорости и толщины)
- 🗄️ **SQLite безопасное хранилище**
- 📝 **Система логирования** (с фильтрацией sensitive данных)
- 📦 **Готовый EXE файл**
- 🐧 **Полная поддержка Linux** (Gnome, KDE, XFCE, Wayland, HiDPI)
