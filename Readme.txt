## 🚀 Что нового в v4.0

### 👤 Генератор имён (новая функция!)
- **8 режимов генерации:** SAMP RP, Email, Игровой ник, Крутой ник, Красивый ник, Короткий (3-5), Длинный (8+), Случайный
- **Выбор пола:** Мужской / Женский / Случайный
- **Выбор языка:** Русский / English
- **Настройка разделителя:** ДА (_) / НЕТ
- **Количество имён:** от 1 до 10 за раз
- **Неоновая рамка** и плавная анимация

### 🎬 Анимация кнопок
- Визуальный отклик при нажатии (уменьшение/возврат за 60 мс)
- Механический звук клика (синхронизирован с анимацией)

### 🌈 RGB подсветка ВСЕГО окна
- Динамическая подсветка всех 4 границ окна
- Синхронизация с заголовком Windows 11
- **Настройка скорости:** Медленная / Нормальная / Быстрая
- **Настройка толщины:** Тонкая (1px) / Средняя (3px) / Толстая (5px)

### 💾 Автосохранение
- Автоматическое сохранение паролей в базу данных
- Метка с датой: `Auto 2026-05-14 15:30:00`
- Включение/выключение через настройки

### 🏗️ Модульная архитектура
- Полная реорганизация проекта на модули
- `core/` - генерация паролей
- `gui/` - интерфейс (16 миксинов)
- `security/` - безопасность (Argon2id, AES, DPAPI)
- `storage/` - база данных и настройки
- `utils/` - утилиты
- `localization/` - локализация

## 🔒 Безопасность

| Защита | Технология |
|--------|------------|
| **Мастер-пароль** | Argon2id + PBKDF2 fallback (600,000 итераций) |
| **Шифрование БД** | AES-256-GCM + SQLCipher |
| **Аппаратное шифрование** | Windows DPAPI |
| **Очистка памяти** | ctypes.memset (пароли не остаются в RAM) |
| **Secure Clipboard** | Windows API (5-кратная перезапись) |
| **Rate Limiting** | 3 ошибки → 5 сек, 5 ошибок → 30 сек |
| **Подпись обновлений** | RSA-PSS |
| **Целостность файлов** | HMAC-SHA256 |
| **Анти-отладка** | IsDebuggerPresent, VM detection |
| **Panic Cleanup** | Аварийная очистка при краше |

### Windows (рекомендуется)
1. Скачайте `SecurePassPro.exe`
2. Запустите файл — установка не требуется
3. При первом запуске мастер-пароль не требуется (можно установить позже)
