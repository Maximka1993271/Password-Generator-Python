Secure Pass Pro

Профессиональный генератор паролей с открытым исходным кодом

Secure Pass Pro — это современный десктопный генератор паролей, построенный на Python и CustomTkinter. Программа сочетает криптографически стойкую генерацию, многоязычный интерфейс (RU/EN/UA), экспорт QR-кодов, контроль целостности файлов через HMAC-SHA256, защиту мастер-паролем (Argon2id + Rate Limiting) и стильный Amoled-дизайн с RGB-анимацией.

  • 🎬 Анимация всех кнопок меню (визуальная обратная связь при нажатии)
  • 🟢🔴 Цветовая индикация (зелёный — включено, красный — выключено)
  • ✅ Неоновые чекбоксы (подсветка при наведении и вспышка при клике)
  • 🔒 Master Password (Argon2id + PBKDF2 fallback + Rate Limiting)
  • 🛡️ Rate Limiting — защита от брутфорса (3→5с, 5→30с)
  • 📝 Система логирования с ротацией и фильтрацией sensitive данных
  • 🧹 Очистка памяти (ctypes.memset) — пароли не остаются в RAM
  • 🔑 Secure Clipboard — защита буфера обмена через Windows API
  • ✅ Контроль целостности HMAC-SHA256 (защита от downgrade attack)
  • 🌈 RGB анимация ВСЕГО окна (границы + заголовок Windows 11)
  • 🗄️ SQLite база паролей с полным шифрованием (label + password)
  • 💾 Автосохранение паролей (вкл/выкл)
  • 🏗️ Полностью модульная архитектура (core/, gui/, security/, storage/, localization/, utils/)
  • 🔄 Panic cleanup — аварийная очистка ресурсов при краше

Ключевые нововведения v4.0

🏗️

Модульная архитектура

Полная реорганизация проекта на модули: core/, gui/, security/, storage/, localization/, utils/. Код стал чище, легче для поддержки и расширения.

🗄️

SQLite база паролей

Безлимитное хранение паролей с полным шифрованием (label + password). Поиск, редактирование и удаление. Защита от SQL-инъекций, Secure delete (PRAGMA).

💾

Автосохранение

Автоматическое сохранение сгенерированных паролей в базу с меткой даты. Включение/выключение через настройки. Перевод на 3 языка (RU/EN/UA).

🎬

Анимация кнопок

Все кнопки меню анимируются при нажатии (уменьшаются и возвращаются за 60 мс) + механический звук клика для приятного тактильного отклика.

🟢🔴

Цветовая индикация

Все переключатели (RGB, звук, автоблокировка, автосохранение) имеют цветовую индикацию: зелёный — включено, красный — выключено.

✅

Неоновые чекбоксы

Чекбоксы имеют неоновую подсветку при наведении и цветную вспышку при клике (зелёная — включение, красная — выключение).

🔒

Argon2id хеширование

Современный стандарт защиты мастер-пароля (победитель Password Hashing Competition) + PBKDF2 fallback для обратной совместимости. Защита от timing-атак через hmac.compare_digest().

🛡️

Rate Limiting

Защита от брутфорса мастер-пароля: 3 ошибки → 5 сек, 4 ошибки → 10 сек, 5 ошибок → 30 сек блокировки.

📝

Система логирования

Ротация логов (5 файлов по 5 МБ), crash reports, фильтрация sensitive данных (пароли и ключи не попадают в логи).

🧹

Очистка памяти

Обнуление паролей через ctypes.memset после использования. Пароли не остаются в RAM.

🔑

Secure Clipboard

Защита буфера обмена через Windows API. Другие процессы не могут читать буфер.

🔄

Panic Cleanup

Аварийная очистка ресурсов при краше: очистка буфера, закрытие БД, остановка анимаций.

✅

Контроль целостности

HMAC-SHA256 контрольные суммы при сохранении и проверка при открытии файлов. Защита от downgrade attack.

🔄

Защита от повторов

Новая опция "Избегать повторов символов подряд" — исключает появление одинаковых символов (aaa, 111). Криптостойкое перемешивание через secrets.randbelow().

👁️

Кнопка-глазок

Одним кликом показывайте или скрывайте пароль. Полная синхронизация с чекбоксом "Скрывать символы".

⌨️

Горячие клавиши

F5 — генерация, Ctrl+C — копирование, Ctrl+S — сохранить, Ctrl+O — открыть, Esc — закрыть диалоги.

🌈

RGB Анимация ВСЕГО ОКНА

Динамическая цветная анимация границ окна с 4 независимыми полосами И синхронизацией заголовка Windows 11 (включая кнопки "Закрыть", "Свернуть", "Развернуть"). Включается/выключается в настройках.

📄

PDF экспорт

Экспорт паролей в PDF с полной поддержкой кириллицы (шрифт DejaVuSans). Исправлена ошибка кодировки latin-1.

🌐

Мультиязычность

Полная поддержка 3 языков: Русский, English, Українська. Мгновенное переключение без перезапуска. Все диалоги и сообщения переведены.

⏱️

Очистка буфера

Настраиваемая очистка буфера обмена от 10 до 120 секунд. Умная очистка — буфер очищается только если в нём всё ещё ваш пароль.
