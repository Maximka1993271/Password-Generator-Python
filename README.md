# 🛡️ Secure Pass Pro v3.9

**🔐 Профессиональный генератор криптостойких паролей**

Современный, быстрый и безопасный инструмент для создания надежных паролей с поддержкой QR-кодов, анализа энтропии и мультиязычного интерфейса.

![v3.9 Preview](https://github.com/Maximka1993271/Password-Generator-Python/raw/main/Secure_Pass_MainWindow39.png)

---

## ✨ Основные возможности

- **Криптостойкая генерация** паролей с использованием `secrets` (CSPRNG).
- **QR-код** для мгновенного переноса пароля на смартфон.
- **Анализ энтропии** + оценка времени взлома (Brute-force на GPU/CPU).
- **Три языка интерфейса**: Английский, Русский, Украинский.
- **Три темы**: Светлая, Тёмная, Системная.
- **Amoled-оптимизация** для OLED и High DPI экранов.
- **Звуковое сопровождение** действий (асинхронный движок).
- **История паролей** (до 50 последних записей).
- **Горячие клавиши** для быстрой работы.
- **Полностью открытый код** с комментариями на трёх языках.

---

## 🚀 Что нового в версии 3.9

- **Modern UI**: Полностью обновлённый дизайн на базе `CustomTkinter`.
- **Type Safety**: Использование `from __future__ import annotations` для поддержки Python 3.9+.
- **QR Engine**: Динамическое обновление QR-кода при каждой генерации.
- **Optimization**: Глобальный кэш системных проверок и использование синглтона для рандома.
- **Linux Fixes**: Улучшенная работа с буфером обмена и уведомления об очистке для X11.
