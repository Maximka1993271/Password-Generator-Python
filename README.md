# 🛡️ Secure Pass Pro v3.9

Профессиональный кроссплатформенный генератор криптостойких паролей.

## 🚀 Последняя версия v3.9
![v3.9 Preview](https://github.com/Maximka1993271/Password-Generator-Python/raw/main/Secure_Pass_MainWindow39.png)

🚀 Что нового в версии v3.9:
Новый современный дизайн: Полностью обновленный интерфейс с улучшенной навигацией и визуальным стилем.

QR-Технологии: Добавлена возможность мгновенного переноса пароля на смартфон через генерацию QR-кода.

Entropy Analysis: Внедрен детальный расчет энтропии и оценка времени, необходимого для взлома пароля.

Triple Localization: Полная поддержка трех языков - английского, русского и украинского.

Amoled UI: Интерфейс оптимизирован для работы на High DPI и OLED экранах для более глубокого черного цвета.

Sound Engine: Добавлено звуковое сопровождение действий (генерация, копирование, ошибки) для лучшего пользовательского отклика.

Трёхъязычный код: Все комментарии в исходном коде теперь продублированы на трёх языках (EN, RU, UA) для удобства разработчиков.

## 💾 Классическая версия v2.0.0
![v2.0.0 Preview](https://github.com/Maximka1993271/Password-Generator-Python/raw/main/Secure_Pass_MainWindow.png)

✨ Что нового в версии 2.0.0
🌍 Локализация и Интерфейс
Полная поддержка UA/RU/EN: Весь интерфейс, сообщения об ошибках и справка теперь доступны на трех языках.

Умные темы: Добавлены Светлая, Темная и Системная темы.

История паролей: Динамическая кнопка истории, показывающая количество сохраненных элементов ИСТОРИЯ (N).

🛠 Исправления и Стабильность (Hotfixes)
Fix #1 (Cross-platform Audio): Устранена критическая ошибка NameError на Linux/macOS. Звуки теперь работают через ленивый импорт winsound только на Windows.

Fix #13 (Resource Path): Улучшена работа с путями в скомпилированном .exe (обработка AttributeError вместо общего перехвата исключений).

Fix #6 (UI Guard): Исправлена ошибка инициализации, когда валидатор длины пароля пытался обратиться к еще не созданному полю ввода.

Fix #8 (Icon Stability): Безопасная загрузка иконки приложения, предотвращающая вылеты на некоторых сборках Windows.

🚀 Улучшения UX
Горячие клавиши:

Ctrl + G - Генерация.

Ctrl + S - Сохранение.

Ctrl + O - Открытие файла.

Скрытие консоли: При запуске на Windows черное окно консоли теперь скрывается автоматически (без нужды в спец-флагах компиляции).

Анализ MD5: Обновленные алгоритмы расчета времени взлома (Brute-force) на современных GPU.
