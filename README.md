# 🛡️ Secure Pass Pro

**🔐 Профессиональный генератор паролей с открытым исходным кодом для Windows, macOS и Linux**

Secure Pass Pro — это современный десктопный менеджер паролей, построенный на Python и CustomTkinter. Программа сочетает криптографически стойкую генерацию, многоязычный интерфейс, экспорт QR-кодов, контроль целостности файлов, защиту мастер-паролем и стильный Amoled-дизайн с RGB-анимацией.

## 📋 О программе

Secure Pass Pro создан для тех, кто ценит безопасность и удобство. Программа генерирует криптостойкие пароли, оценивает их надёжность, сохраняет в файлы различных форматов и позволяет быстро передать пароль через QR-код.

### 🎯 Основные возможности

| Функция | Описание |
|---------|----------|
| 🎬 **Анимация кнопок** | Живой отклик — текст кнопок мгновенно сжимается при нажатии |
| 🔐 **Генерация паролей** | Криптостойкая генерация с использованием модуля `secrets` и CSPRNG |
| 📊 **Оценка стойкости** | Расчёт энтропии в битах, время взлома, 5-звёздочный рейтинг |
| 🎨 **Цветная пульсация** | Визуальная индикация силы пароля: 🔴 слабый / 🟠 средний / 🟢 надёжный |
| 🌈 **RGB анимация** | Динамическая цветная анимация **ВСЕГО окна**: 4 границы + заголовок Windows 11 |
| 🔒 **Мастер-пароль** | Argon2id хеширование (современный стандарт) + PBKDF2 fallback |
| 🛡️ **Rate Limiting** | Защита от брутфорса: 3 ошибки → 5 сек, 5 ошибок → 30 сек блокировки |
| 📝 **Система логирования** | Ротация логов (5 файлов по 5 МБ), crash reports, фильтрация sensitive данных |
| 🧹 **Очистка памяти** | Обнуление паролей через ctypes.memset после использования |
| 🔑 **Secure Clipboard** | Защита буфера обмена через Windows API |
| ✅ **Контроль целостности** | HMAC-SHA256 проверка файлов при открытии |
| 📄 **Экспорт в PDF** | Полная поддержка кириллицы через шрифт DejaVuSans |
| 📱 **QR-код** | Быстрая передача пароля на мобильные устройства |
| 📜 **История паролей** | Сохранение последних 50 паролей (маскированных) |
| 🗄️ **SQLite хранилище** | Безлимитное хранение паролей с полным шифрованием (label + password) |
| 🔌 **Пул соединений БД** | Singleton connection pool для производительности |
| 🌐 **Мультиязычность** | Интерфейс на русском, английском и украинском языках |
| 🎨 **Темы оформления** | Системная, светлая, тёмная |
| ⏱️ **Умная очистка буфера** | Автоматическая очистка через 10-120 секунд (настраивается) |
| 🖱️ **Контекстное меню** | Правая кнопка мыши: Копировать/Вставить/Очистить/Выделить всё |
| ⌨️ **Горячие клавиши** | F5, Ctrl+C, Ctrl+S, Ctrl+O, Esc |
| 📐 **Скругление углов** | Настройка радиуса всех элементов интерфейса от 0 до 25 пикселей |
| 💻 **Кроссплатформенность** | Полная поддержка Windows, macOS и Linux |
| 💾 **Автосохранение** | Автоматическое сохранение паролей в SQLite базу (вкл/выкл через настройки) |
| 🔄 **Паника-очистка** | Глобальный emergency cleanup при краше |

## 📦 Установка и запуск

### Windows (рекомендуется)

1. Скачайте `SecurePassPro.exe` из раздела [Releases](https://github.com/Maximka1993271/Password-Generator-Python/releases)
2. Запустите файл — установка не требуется
3. При первом запуске можно установить мастер-пароль
4. Все данные сохраняются в папке `data/` рядом с EXE

### Из исходного кода (macOS, Linux, Windows)

```bash
# Клонирование репозитория
git clone https://github.com/Maximka1993271/Password-Generator-Python.git
cd Password-Generator-Python

# Создание виртуального окружения (рекомендуется)
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

# Установка зависимостей
pip install customtkinter qrcode[pil] pillow fpdf argon2-cffi cryptography

# Запуск v4.0
python3 Secure_Pass_Pro.pyw
