## ✨ Основные возможности v3.9

- **Криптостойкая генерация**: Использование модуля `secrets` (CSPRNG) для максимальной защиты.
- **Динамический дизайн (UI/UX)**: 
  - Ползунок **закругления углов** в реальном времени для всех элементов интерфейса.
  - Адаптивные темы: Светлая, Тёмная и Системная (исправлено отображение панелей в светлом режиме).
- **Умная фильтрация**:
  - Исключение похожих символов (i, l, 1, L, o, 0, O).
  - Исключение **не однозначных знаков** для повышения читаемости.
- **Безопасность**: 
  - Автоматическая очистка буфера обмена через 60 секунд.
  - Поддержка расширений `.key`, `.log` и `.txt` для работы с ключами и системными логами.
- **Анализ энтропии**: Расчет времени взлома и визуальный индикатор надежности со звездным рейтингом.
- **QR-код**: Мгновенный перенос пароля на мобильное устройство.
- **Мультиязычность**: Полная поддержка RU, EN, UA с мгновенным переключением.

## 🚀 Что нового в финальной версии 3.9

1. **Рефакторинг интерфейса**: Дизайн стал более сбалансированным. Кнопки управления логически сгруппированы в боковом меню с цветовой кодировкой.
2. **Исправление терминологии**: Параметр «сложные знаки» заменен на **«не однозначные»**, что точнее отражает суть функции.
3. **Оптимизация под Windows 11 Pro**:
   - Звуковое сопровождение реализовано через нативный Windows API (`winsound`), обеспечивая мягкие системные уведомления.
   - Полная поддержка High DPI для четкого отображения на современных мониторах.
4. **Улучшенная светлая тема**: Нижняя панель управления теперь динамически меняет цвет, подстраиваясь под общую тему оформления.
5. **История 2.0**: Расширенная история на 50 последних паролей с отметками времени.
