# 🔐 🛡️ Secure Pass Pro v3.9

Secure Pass Pro - это профессиональный инструмент с открытым исходным кодом для генерации криптостойких паролей. Программа сочетает в себе максимальную безопасность, современный UX в стиле Amoled и полную портативность.

## 📸 Интерфейс / Interface

![Secure Pass Pro Interface](Secure_Pass_MainWindow39.png)

## 🌟 Основные возможности

🎨 Дизайн и UX (Refined)
Amoled Dark Theme: Глубокий черный интерфейс для комфортной работы и экономии заряда на OLED-экранах.

Color-Coded Actions: Интуитивно понятная цветовая схема кнопок для быстрого ориентирования:

🔵 Синий: Генерация нового криптостойкого пароля.

🟢 Зелёный: Безопасное копирование в буфер обмена.

🐬 Бирюзовый: Работа с файлами (Сохранение и Открытие базы паролей).

🟣 Фиолетовый: Создание QR-кода для быстрой передачи на смартфон.

🔘 Серый: Просмотр истории генераций в текущей сессии.

🟠 Оранжевый: Мгновенная проверка и загрузка обновлений программы.

High DPI Awareness: Принудительная поддержка высокого разрешения (4K/2K) - все элементы остаются четкими.

Triple Localization: Полная поддержка трех языков - Русский, English, Українська.

Dynamic UI: Настройка радиуса закругления углов (от 0 до 20px) прямо в интерфейсе.

---

### 🔊 Мультимедийный отклик (NEW)

🔊 Мультимедийный отклик (Refined)
Sound Effects: Интегрированная система звуковых уведомлений (через winsound) для подтверждения действий:

Генерация: Одиночный сигнал (1000Hz).

Копирование/Сохранение: Двойной каскадный сигнал (1500Hz -> 2000Hz).

Cross-Platform Silence: Доступно для Windows (ленивый импорт winsound), на других ОС программа работает в бесшумном режиме без ошибок импорта.

---

🛡️ Безопасность (Security First)
CSPRNG (secrets): Использование модуля secrets для генерации паролей, соответствующих стандартам криптографии.

Complexity Analysis: Динамическая оценка энтропии и прогноз времени взлома (Time-to-Crack) на основе мощностей в 10 млрд проверок/сек.

Ambiguity Filter: Исключение похожих символов (i, l, 1, L, o, 0, O) для предотвращения ошибок ввода.

At-Least-One Logic: Гарантированное наличие минимум одного символа из каждой выбранной категории (заглавные, строчные, цифры, знаки).

---

### 💾 Файловая логика и стабильность (Refined)

Zero-Config Logic: Работа без файла config.ini. Все настройки применяются на лету, обеспечивая идеальную портативность.

Resource Resilience: Улучшенная функция resource_path (обработка AttributeError) гарантирует стабильное отображение иконки даже при сборке в единый .exe.

Smart Save: Кнопка «Сохранить» (Ctrl+S) автоматически вызывает диалог, если файл не выбран, или обновляет текущий.

Keyboard Shortcuts: Полноценная поддержка горячих клавиш (Ctrl+G, Ctrl+S, Ctrl+O) с корректной обработкой фокуса в полях ввода.

---

📊 Инструменты и Аналитика
QR-Code Generator: Мгновенная передача пароля на мобильное устройство без использования облачных буферов обмена.

History Manager: Локальный просмотр сессии генерации (очищается при закрытии).

Smart Save: Быстрое сохранение в .txt с автоматическим форматированием.

---

🛠 Технический стек
Core: Python 3.10+

GUI: customtkinter (модернизированный Tkinter)

Graphics: Pillow (обработка иконок и QR)

QR: qrcode

Security: secrets, string, hashlib

---

🚀 Новое в версии v3.9
Direct Update System: Кнопка «Обновить программу» теперь ведет на прямую загрузку последней версии .exe с GitHub Releases.

Enhanced Stability: Полностью переписана логика инициализации - программа работает без внешних конфигурационных файлов (config.ini), сохраняя настройки в памяти.

Sound Feedback (Windows): Звуковое подтверждение генерации (1000Hz) и копирования (каскад 1500Hz -> 2000Hz).

Silent Mode (Linux/macOS): Автоматическое отключение звуков на системах без winsound без ошибок импорта.

* Python 3.14.4

```bash

```

