## 📋 О программе

**Secure Pass Pro v4.0** — это профессиональный генератор и менеджер паролей с открытым исходным кодом. Программа построена на Python и CustomTkinter, сочетает криптостойкую генерацию, многоязычный интерфейс, полное шифрование данных и современный дизайн с RGB-анимацией.

| Параметр | Значение |
|----------|----------|
| **Автор** | Максим Мельников |
| **Лицензия** | MIT (бесплатно) |
| **Версия** | 4.0.0 |
| **Платформы** | Windows, macOS, Linux |
| **Языки** | Русский, English, Українська |

---

## 🚀 Основные возможности

| № | Функция | Описание |
|---|---------|----------|
| 1 | 👤 **Генератор имён** | 8 режимов: SAMP RP, Email, Игровой ник, Крутой ник, Красивый ник, Короткий, Длинный, Случайный |
| 2 | 🔐 **Генерация паролей** | Криптостойкая генерация с 8 параметрами (CSPRNG) |
| 3 | 🗄️ **База паролей** | SQLite с полным шифрованием (AES-256-GCM + SQLCipher) |
| 4 | 🔒 **Мастер-пароль** | Argon2id хеширование + PBKDF2 fallback |
| 5 | 🛡️ **Rate Limiting** | Защита от брутфорса (3 ошибки → 5 сек, 5 ошибок → 30 сек) + персистентность |
| 6 | 🌈 **RGB анимация** | Динамическая подсветка всего окна (4 границы + заголовок) с настройкой скорости и толщины |
| 7 | 🎬 **Анимация кнопок** | Визуальный отклик + механический звук |
| 8 | 🔑 **Secure Clipboard** | Защита буфера обмена (5-кратная перезапись) + отслеживание владельца |
| 9 | 🧹 **Очистка памяти** | Обнуление паролей через ctypes.memset + MemoryGuard контекст |
| 10 | 📝 **Система логирования** | Ротация логов, фильтрация sensitive данных (пароли, ключи, токены) |
| 11 | ✅ **Контроль целостности** | HMAC-SHA256 проверка файлов, fail-closed поведение |
| 12 | 📄 **PDF экспорт** | Полная поддержка кириллицы + тёмная/светлая тема |
| 13 | 📱 **QR-код** | Быстрая передача пароля на мобильные устройства |
| 14 | 🔄 **Автообновление** | Проверка подписи SHA-256, верификация целостности |
| 15 | 💾 **Автосохранение** | Автоматическое сохранение паролей в базу |
| 16 | 📜 **История** | Сохранение последних 50 паролей |
| 17 | 🖱️ **Контекстное меню** | Правая кнопка мыши |
| 18 | ⌨️ **Горячие клавиши** | F5, Ctrl+C, Ctrl+S, Ctrl+O, Esc |
| 19 | 🌐 **Полная локализация** | Полная поддержка RU, EN, UA с динамическим переключением |
| 20 | 🔄 **Fallback язык** | Автоматическое восстановление отсутствующих ключей |

## 📦 Установка и запуск

### Windows (рекомендуется)

1. Скачайте `SecurePassPro.exe` из раздела [Releases](https://github.com/Maximka1993271/Password-Generator-Python/releases)
2. Запустите файл — установка не требуется
3. При первом запуске мастер-пароль не требуется (можно установить позже)
4. Все данные сохраняются в папке `data/` рядом с EXE

### Linux

```bash
# Установка зависимостей
sudo apt install python3-tk mpg123  # для звука

# Клонирование репозитория
git clone https://github.com/Maximka1993271/Password-Generator-Python.git
cd Password-Generator-Python

# Установка Python зависимостей
pip install customtkinter qrcode[pil] pillow fpdf argon2-cffi cryptography requests

# Запуск программы
python3 Secure_Pass_Pro.pyw
