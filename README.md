## 📋 О программе

**Secure Pass Pro v4.0** — это профессиональный генератор и менеджер паролей. Программа использует криптографически стойкие алгоритмы, полное шифрование данных и современный интерфейс с RGB-анимацией.

| Параметр | Значение |
|----------|----------|
| **Автор** | Максим Мельников |
| **Лицензия** | MIT (бесплатно) |
| **Версия** | 4.0.0 |
| **Платформы** | Windows, macOS, Linux |

---

## 🚀 Основные возможности

| № | Функция | Описание |
|---|---------|----------|
| 1 | 👤 **Генератор имён** | 8 режимов: SAMP RP, Email, Игровой ник, Крутой ник, Красивый ник, Короткий, Длинный, Случайный |
| 2 | 🔐 **Генерация паролей** | Криптостойкая генерация с 8 параметрами |
| 3 | 🗄️ **База паролей** | SQLite с полным шифрованием (AES-256-GCM + SQLCipher) |
| 4 | 🔒 **Мастер-пароль** | Argon2id хеширование + PBKDF2 fallback |
| 5 | 🛡️ **Rate Limiting** | Защита от брутфорса (3→5с, 5→30с) |
| 6 | 🌈 **RGB анимация** | Динамическая подсветка всего окна |
| 7 | 🎬 **Анимация кнопок** | Визуальный отклик + механический звук |
| 8 | 🔑 **Secure Clipboard** | Защита буфера обмена (5-кратная перезапись) |
| 9 | 📄 **PDF экспорт** | Полная поддержка кириллицы |
| 10 | 📱 **QR-код** | Быстрая передача пароля |
| 11 | 📜 **История** | Сохранение последних 50 паролей |
| 12 | 💾 **Автосохранение** | Автоматическое сохранение в базу |

---

## 🔒 Безопасность

| Защита | Технология |
|--------|------------|
| Мастер-пароль | Argon2id + PBKDF2 fallback |
| Шифрование БД | AES-256-GCM + SQLCipher |
| Аппаратное шифрование | Windows DPAPI |
| Очистка памяти | ctypes.memset |
| Secure Clipboard | Windows API (5x overwrite) |
| Rate Limiting | 5 попыток → блокировка |
| Подпись обновлений | RSA-PSS |
| Целостность файлов | HMAC-SHA256 |
