# 🔐 Secure Pass Pro v1.9.2 Stable

Secure Pass Pro - это профессиональный кроссплатформенный инструмент для генерации паролей, созданный на Python. Программа сочетает в себе максимальную криптостойкость, современный интерфейс в стиле "Amoled Black" и безупречную визуальную логику с мультимедийным откликом.

## 📸 Интерфейс / Interface

![Secure Pass Pro Interface](Secure_Pass_MainWindow.png)

## 🌟 Основные возможности

### 🎨 Дизайн и UX (Refined)

* **Amoled Dark Theme:** Глубокий черный интерфейс в стиле AdGuard для комфортной работы и экономии энергии на OLED-экранах.

* **Color-Coded Actions:** Интуитивно понятная цветовая схема кнопок:

  * 🔵 Синий: Генерация нового пароля.
  * 🟢 Зелёный: Безопасное копирование в буфер.
  * 🟣 Фиолетовый: Создание QR-кода.

* **Smart Centering (NEW):** Все диалоговые окна, уведомления и QR-коды автоматически центрируются относительно главного окна приложения.

* **High DPI Awareness:** Принудительная поддержка высокого разрешения (4K/2K) — шрифты и элементы интерфейса остаются четкими.

* **Visual Integrity:** Единая иконка приложения для всех дочерних окон и системных уведомлений.

* **Dynamic Feedback:** Анимированные кнопки и интерактивные подсказки при наведении.

* **Full Localization:** Полная поддержка трех языков — Русский, English, Українська.

---

### 🔊 Мультимедийный отклик (NEW)

* **Sound Effects:** Интегрированная система звуковых уведомлений (через winsound) для подтверждения действий:

  * Генерация: Одиночный сигнал (1000Hz).
  * Копирование/Сохранение: Двойной каскадный сигнал (1500Hz -> 2000Hz).

> Доступно для Windows, на других ОС программа работает в бесшумном режиме.

---

### 🛡️ Безопасность (Security First)

* **Crypto-Grade:** Использование модуля `secrets` для генерации паролей, которые практически невозможно предугадать.

* **Secure Wipe:** Автоматическая очистка буфера обмена ровно через 60 секунд.

* **Zero-Footprint:** Программа не хранит историю в открытом виде и полностью очищает оперативную память при закрытии.

---

### 💾 Файловая логика и стабильность (Refined)

* **Smart Save:** Кнопка «Сохранить» автоматически вызывает диалог «Сохранить как», если файл еще не был создан.

* **Валидация пути:** Проверка физического наличия файла перед каждой записью — защита от ошибок при перемещении файла вручную.

* **Атомарные обновления:** Путь к рабочему файлу фиксируется в памяти только после успешного завершения записи на диск.

* **Resource Resilience:** Использование `resource_path` гарантирует стабильную работу иконок при сборке в единый `.exe`.

---

### 📊 Аналитика и Инструменты

* **Time-to-Crack:** Визуальный индикатор времени, необходимого для взлома пароля методом брутфорса.

* **QR-Code Generator:** Мгновенная генерация QR-кода с адаптивной темой (светлая/темная) для безопасной передачи пароля на смартфон.

* **Entropy Analysis:** Трёхуровневая цветовая шкала оценки сложности пароля.

* **Update Checker:** Встроенная кнопка быстрой проверки новых версий проекта на GitHub.

---

### 🛠 Технические подробности

* **Кроссплатформенность:** Полная совместимость с Windows, Linux и macOS.

* **Умная адаптация:** Автоматическое определение и применение системной темы оформления при запуске.

* **Clean Code:** Исходный код снабжен подробными комментариями на трех языках (RU/EN/UA) и соответствует принципам DRY.

## 📥 Для пользователей (Windows Portable)

1. Перейдите в раздел **[Релизы](https://github.com/Maximka1993271/Password-Generator-Python/releases)**.
2. Скачайте актуальный файл **[📥 Secure_Pass_Pro.exe](https://github.com/Maximka1993271/Password-Generator-Python/releases/download/SecurePassProv1.9.2/Secure_Pass_Pro.exe)**.
3. Программа является Portable — просто запустите её, установка не требуется.

---

## 💻 Для разработчиков

### Требования:

* Python 3.14.4

### Установка зависимостей:

```bash
pip install pillow qrcode
```

### Запуск:

```bash
python Secure_Pass_Pro.pyw
```

### Сборка в .exe (Windows):

```bash
pyinstaller --onefile --noconsole --icon="app_icon.ico" --add-data "app_icon.ico;." --hidden-import=qrcode --collect-submodules qrcode Secure_Pass_Pro.pyw
```
