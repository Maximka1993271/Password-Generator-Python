## 📋 О программе

**Secure Pass Pro v4.0** — это профессиональный генератор и менеджер паролей с открытым исходным кодом. Программа построена на Python и CustomTkinter, сочетает криптостойкую генерацию, многоязычный интерфейс, полное шифрование данных и современный дизайн с RGB-анимацию.

## 🆕 НОВЫЕ ФУНКЦИИ В v4.0

### 🔐 **Двухфакторная аутентификация (2FA)**

**Полная поддержка TOTP (Time-based One-Time Password) — совместимость с Google Authenticator, Authy, Microsoft Authenticator и другими приложениями.**

| Функция | Описание |
|---------|----------|
| **TOTP генерация** | 6-значные коды, интервал 30 секунд, алгоритм SHA1/SHA256/SHA512 |
| **QR-код** | Автоматическая генерация QR для быстрой настройки |
| **Резервные коды** | 10 резервных кодов для восстановления доступа |
| **Anti-replay защита** | Защита от повторного использования кодов |
| **Brute-force защита** | Rate limiting: 5 попыток за 60 секунд |
| **Регенерация кодов** | Возможность сгенерировать новые резервные коды |
| **Отключение 2FA** | С подтверждением текущего кода |
| **Полная локализация** | Интерфейс 2FA переведён на 3 языка |

**Как настроить 2FA:**
1. Установите мастер-пароль
2. Откройте Настройки → Безопасность → 2FA
3. Нажмите "Включить 2FA"
4. Отсканируйте QR-код приложением-аутентификатором
5. Введите полученный код для подтверждения
6. Сохраните резервные коды в надёжном месте
