## 📋 О программе

Secure Pass Pro создан для тех, кто ценит безопасность и удобство. Программа генерирует криптостойкие пароли, оценивает их надёжность, сохраняет в файлы различных форматов и позволяет быстро передать пароль через QR-код.

**Программа прошла полный аудит безопасности и стабильности:** 29+ исправлений, включая 6 критических исправлений безопасности.

## 🛡️ Защита от вредоносных программ

- Программа **не собирает и не передаёт** ваши пароли
- Генерация происходит **локально** на вашем устройстве
- Нет **телеметрии** и рекламы
- **Открытый исходный код** — любой может проверить безопасность

---

## 🔐 Криптография паролей

- Использование **CSPRNG** (Cryptographically Secure Pseudorandom Number Generator)
- Модуль Python `secrets` — криптографически стойкий генератор
- **PBKDF2** для хранения мастер-пароля (100,000 итераций)
- **HMAC** защита от timing-атак
- **SHA-256** для контроля целостности файлов

---

## 📜 Политика защиты

- Пароли **не сохраняются** в открытом виде (история маскируется)
- Буфер обмена очищается **автоматически**
- Мастер-пароль **не хранится** в открытом виде
- Конфигурация сохраняется в **локальной папке пользователя**

---

## 🧠 Умная система проверки

- **Энтропия** — математический расчёт сложности пароля в битах
- **Time-to-Crack** — оценка времени взлома методом перебора
- **5-звёздочный рейтинг** — визуальная оценка надёжности
- **Цветная пульсация** — мгновенная визуальная обратная связь
