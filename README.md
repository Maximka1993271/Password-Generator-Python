🔐 Secure Pass Pro v1.8.9 Stable
Secure Pass Pro - это мощный, кроссплатформенный инструмент для генерации паролей, созданный на Python. Программа сочетает в себе максимальную криптостойкость, современный интерфейс в стиле "Amoled Black" и мультимедийный отклик.

🌟 Основные возможности
🎨 Дизайн и UX
Amoled Dark Theme: Глубокий черный интерфейс в стиле AdGuard для комфортной работы и экономии энергии на OLED-экранах.

Color-Coded Actions: Интуитивно понятные цветные кнопки: 🔵 Генерация, 🟢 Копирование, 🟣 QR-код.

Full Localization: Полная поддержка трех языков — Русский, English, Українська.

Dynamic Feedback: Анимированные кнопки и интерактивные подсказки при наведении.

🔊 Мультимедийный отклик (NEW)
Sound Effects: Интегрированная система звуковых уведомлений (через winsound) для подтверждения генерации и копирования данных.

🛡️ Безопасность (Security First)
Crypto-Grade: Использование модуля secrets для генерации паролей, которые невозможно предугадать.

Secure Wipe: Автоматическая очистка буфера обмена через 60 секунд.

Zero-Footprint: Программа не хранит историю паролей в открытом виде и очищает память при закрытии.

💾 Файловая логика и стабильность (Refined)
Smart Save: Кнопка «Сохранить» автоматически вызывает «Сохранить как», если файл еще не создан.

Валидация пути: Проверка физического наличия файла перед записью — защита от ошибок, если файл был удален вручную.

Атомарные обновления: Путь к файлу сохраняется в памяти только после успешной записи на диск.

📊 Аналитика и Инструменты
Time-to-Crack: Визуальный индикатор времени, необходимого для взлома пароля методом брутфорса.

QR-Code Generator: Мгновенная генерация QR-кода с адаптивной темой для передачи пароля на смартфон.

Entropy Analysis: Трёхуровневая цветовая шкала оценки сложности.

Update Checker: Встроенная кнопка быстрой проверки новых версий на GitHub.

🛠 Технические подробности
Кроссплатформенность: Полная совместимость с Windows, Linux и macOS.

Умная адаптация: Автоматическое определение системной темы оформления.

Clean Code: Исходный код снабжен подробными комментариями на трех языках (RU/EN/UA).

💻 Для разработчиков
Требования: Python 3.x

Установка зависимостей:
pip install pillow qrcode

Запуск:
python Secure_Pass_Pro.pyw

Сборка в .exe (Windows):
pyinstaller --onefile --noconsole --icon="app_icon.ico" --add-data "app_icon.ico;." Secure_Pass_Pro.pyw
