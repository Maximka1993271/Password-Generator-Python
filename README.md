## 📋 О программе

**Secure Pass Pro v4.0** — это профессиональный генератор и менеджер паролей с открытым исходным кодом. Программа построена на Python и CustomTkinter, сочетает криптостойкую генерацию, многоязычный интерфейс, полное шифрование данных и современный дизайн с RGB-анимацией.

| Параметр | Значение |
|----------|----------|
| **Автор** | Максим Мельников |
| **Лицензия** | MIT (бесплатно) |
| **Версия** | 4.0.0 |
| **Платформы** | Windows, macOS, Linux |
| **Языки** | Русский, English, Українська |

## 🚀 Основные возможности

| № | Функция | Описание |
|---|---------|----------|
| 1 | 👤 **Генератор имён** | 8 режимов: SAMP RP, Email, Игровой ник, Крутой ник, Красивый ник, Короткий, Длинный, Случайный |
| 2 | 🔐 **Генерация паролей** | Криптостойкая генерация с 8 параметрами (CSPRNG) |
| 3 | 🗄️ **База паролей** | SQLite с полным шифрованием (AES-256-GCM + SQLCipher) |
| 4 | 🔒 **Мастер-пароль** | Argon2id хеширование + PBKDF2 fallback |
| 5 | 🛡️ **Rate Limiting** | Защита от брутфорса + персистентность |
| 6 | 🌈 **RGB анимация** | Динамическая подсветка окна с настройкой скорости и толщины |
| 7 | 🔑 **Secure Clipboard** | Защита буфера обмена (5-кратная перезапись) |
| 8 | 🧹 **Очистка памяти** | Обнуление паролей через ctypes.memset |
| 9 | 📝 **Система логирования** | Ротация логов, фильтрация sensitive данных |
| 10 | ✅ **Контроль целостности** | HMAC-SHA256 проверка файлов |
| 11 | 📄 **PDF экспорт** | Полная поддержка кириллицы + тёмная/светлая тема |
| 12 | 📱 **QR-код** | Быстрая передача пароля на мобильные устройства |
| 13 | 🔄 **Автообновление** | Проверка подписи SHA-256 |
| 14 | 💾 **Автосохранение** | Автоматическое сохранение паролей в базу |
| 15 | 📜 **История** | Сохранение последних 50 паролей |
| 16 | 🌐 **Полная локализация** | RU, EN, UA с динамическим переключением |
| 17 | 🐧 **Кросс-платформенность** | Windows, macOS, Linux |
| 18 | 📦 **Портативный режим** | Работа с флешки |

## 🆕 Новые функции в v4.0

### 🔐 Двухфакторная аутентификация (2FA)
- TOTP совместимость с Google Authenticator, Authy
- QR-код для быстрой настройки
- 10 резервных кодов
- Anti-replay и brute-force защита

### 🌐 Полная поддержка 3 языков
- Русский (RU) ✅
- English (EN) ✅
- Українська (UA) ✅

### 📤 Экспорт данных
- JSON, CSV, HTML
- Шифрование AES-256-GCM
- Выбор полей и кодировки

### 📥 Импорт данных (6 форматов)
- JSON, CSV, KeePass XML, Bitwarden JSON, 1Password CSV, 1PUX

### 🎨 Современный дизайн настроек
- Боковая панель с категориями
- Карточки с описаниями
- Поиск по настройкам
- Профили настроек

### 🖨️ HTML экспорт
- Поиск, сортировка, печать
- Копирование пароля кликом
- Полная локализация
