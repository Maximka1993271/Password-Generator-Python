От генерации до хранения — полный инструментарий в одной программе

🔐

Генератор паролей

8 параметров настройки. CSPRNG — криптографически стойкий генератор на базе secrets. Визуальная индикация надёжности.

🎲

Фразы-пароли Diceware

EFF Diceware словарь — 7 776 слов. ~13 бит энтропии на слово. «верба лиман слон кофта» легче запомнить и труднее взломать.

🗄️

База паролей

Полное шифрование через SQLCipher. Каждое поле — AES-256-GCM с тегом аутентификации. Категории, теги, избранное, поиск.

🛡️

2FA / TOTP

Совместимость с Google Authenticator, Authy, 1Password. 10 одноразовых резервных кодов. Rate limiting на перебор.

☁️

Облачная синхронизация

WebDAV — Nextcloud, pCloud, Box и любой совместимый сервер. В облако уходит только зашифрованный файл. Ключ остаётся на устройстве.

⌨️

Auto-Type

Автоматический ввод пароля в активное поле без буфера обмена. Windows: SendInput. Linux: xdotool. macOS: osascript.

📋

Secure Clipboard

5-кратная перезапись буфера обмена случайными данными. Автоочистка по таймауту (по умолчанию 60 сек).

📄

PDF экспорт

Тёмная и светлая темы. Полная поддержка кириллицы через встроенный шрифт DejaVu Sans. Без зависимостей от ОС.

🔍

Проверка утечек HIBP

Have I Been Pwned через k-Anonymity: только первые 5 символов SHA-1 хэша отправляются на сервер. Пароль не передаётся.

Шаги установки 
# 1. Скачайте SecurePassPro.exe из Releases
# 2. Запустите файл
# 3. При первом запуске задайте мастер-пароль
#
# Если Windows SmartScreen показывает предупреждение:
# Нажмите «Подробнее» → «Всё равно запустить»
#
# Проверка SHA-256 (рекомендуется):
certutil -hashfile SecurePassPro.exe SHA256
bash / PowerShell 
# Клонировать репозиторий
git clone https://github.com/Maximka1993271/Password-Generator-Python.git
cd Password-Generator-Python

# Создать виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate    # Windows
source venv/bin/activate  # Linux / macOS

# Установить зависимости
pip install -r requirements.txt

# Запустить
python Secure_Pass_Pro.pyw
PowerShell 
# Установить PyInstaller
pip install pyinstaller>=6.0.0

# Запустить сборку
python build.py

# Готовый файл:
dist\SecurePassPro.exe  # ~60 MB, всё включено
